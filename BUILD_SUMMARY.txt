REPLAY PREVENTION MECHANISM
───────────────────────────

How It Works:

  1. Request 1: Sign(totalValue=100)
     → Facilitator verifies: 100 > 0 ✓
     → Stores: lastTotalValue=100

  2. Request 2: Sign(totalValue=200)
     → Facilitator verifies: 200 > 100 ✓
     → Stores: lastTotalValue=200

  3. Replay Attempt: Sign(totalValue=100)
     → Facilitator verifies: 100 > 200? ✗
     → REJECTED with invalidReason: "totalValue_not_incremental"

Storage:
  Key: ${client.toLowerCase()}:${server.toLowerCase()}
  Value: { lastTotalValue, lastSignature, requestCount, lastVerifiedAt }
